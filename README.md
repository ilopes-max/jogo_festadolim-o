🍋 Jogo de Pegar Itens da Limãozinho

Um jogo simples e divertido em que o jogador controla a personagem Limãozinho e precisa pegar os itens que aparecem na tela para marcar pontos.

📌 Sobre o projeto

O objetivo do jogo é movimentar a Limãozinho pela tela e coletar o maior número possível de itens.

O projeto foi desenvolvido com foco em praticar conceitos de programação, movimentação de personagens, colisões, pontuação e interação com o jogador.

🎮 Como jogar
Use as teclas de movimentação para controlar a Limãozinho;
Pegue os itens que aparecem na tela;
Cada item coletado aumenta sua pontuação;
Tente conseguir a maior pontuação possível!
🚀 Funcionalidades
Movimentação da personagem;
Sistema de coleta de itens;
Contador de pontos;
Interação com o teclado;
Sistema simples e divertido de gameplay.

🎯 Objetivo

Este projeto foi criado para praticar lógica de programação, eventos de teclado, movimentação, colisões e criação de jogos utilizando Python.
